# Security Policy

## Reporting a vulnerability

**Please don't open a public issue for security problems.** Report privately via
the affected repository's **Security → Report a vulnerability** (private
vulnerability reporting), or contact the maintainer directly.

We aim to acknowledge reports promptly. Include reproduction steps and the
affected commit.

## Practices

- Commits are **cryptographically signed** and verified.
- Default branches are **protected**; changes land through reviewed pull requests.
- **Secrets are never committed** to git.

## Supported versions

Only the latest default branch of each repository is supported.
