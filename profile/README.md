# HomeLab-Forge

A private, self-hosted homelab, managed as code.

Repositories are private, with one exception:
[`bitwig-samples`](https://github.com/HomeLab-Forge/bitwig-samples), free SFZ drum
kits ported to Bitwig Studio, one release per kit, with the tools that build them.

Contributions follow **signed-commit**, **squash**, and **protected default
branch** policies — see `CONTRIBUTING.md` and `SECURITY.md`.
