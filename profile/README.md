# HomeLab-Forge

A private, self-hosted homelab, managed as code.

Repositories are private, with one exception:
[`bitwig-samples`](https://github.com/HomeLab-Forge/bitwig-samples), free sample
libraries ported to Bitwig Studio, one release per library, with the tools that
build them. Drum kits so far; pianos and synths are next.

Contributions follow **signed-commit**, **squash**, and **protected default
branch** policies — see `CONTRIBUTING.md` and `SECURITY.md`.
