# Contributing

- **Sign your commits.** Commit signing is required; your signature must be
  verifiable (register your signing key on your GitHub account so commits show
  **Verified**).
- **Branch → pull request → squash.** Default branches are protected; PRs merge
  as a single **squashed** commit. Delete the branch after merge.
- **Commit messages:** imperative, prefixed by type — `feat:`, `fix:`, `docs:`,
  `chore:`, `refactor:`.
- **Never commit secrets** — no credentials, keys, or certificates in git.
- **Run the repository's linters/checks** before opening a pull request.
